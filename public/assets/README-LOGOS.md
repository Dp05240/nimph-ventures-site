# Nimph Ventures Logo Files

Three versions of the Nimph logo for different use cases.

## Files

### 1. `nimph-logo.svg` (Light version)
- **Text color**: Off-white (#E8ECF1)
- **Use case**: Dark backgrounds, presentations, website
- **Size**: 400x100px

### 2. `nimph-logo-dark.svg` (Dark version)
- **Text color**: Near-black (#0A0E14)
- **Use case**: Light backgrounds, Word documents, letterheads, print
- **Size**: 400x100px

### 3. `nimph-logo-letterhead.svg` (Full letterhead version)
- **Text color**: Near-black (#0A0E14)
- **Includes**: "Nimph." + "Ventures LLC" subtitle
- **Use case**: Official letterheads, business documents, contracts
- **Size**: 600x120px

## How to Use in Microsoft Word

### Method 1: Insert as SVG (Recommended - Word 2016+)

1. Open Word document
2. Click **Insert** → **Pictures** → **This Device**
3. Select the `.svg` file (use `nimph-logo-dark.svg` for most documents)
4. The logo will remain crisp at any size

### Method 2: Insert as Picture

1. Drag and drop the `.svg` file into your Word document
2. Resize as needed (it will scale perfectly)

### For Letterheads:

1. Use `nimph-logo-letterhead.svg`
2. Place in the header section
3. Typical size: 2-3 inches wide
4. Position: Top left or centered

## Need Customization?

All logos use system fonts:
- Font: system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif
- Weight: 700 (Bold)
- Letter spacing: Tight (-1 to -1.5)

You can edit the SVG files in any text editor to adjust:
- Size (change viewBox and font-size)
- Colors (change fill attribute)
- Spacing (change x, y coordinates)
